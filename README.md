# Kim Cedrick Villar — Studio Portfolio

A single-page developer portfolio for Laboratory Activity 1. The redesigned site uses an original studio-editorial visual system with responsive HTML, CSS, and JavaScript only.

## Stack

- HTML
- CSS
- JavaScript

No framework, backend, database, external API, or deployed-site link is required. The contact form is a client-side visual prototype only.

## Run locally

Open `index.html` in a browser, or serve this folder with any simple static HTTP server.

## Included requirements

- Semantic header, navigation, main sections, articles, table, form, and footer
- About section with three or more sentences
- Five technical skills in an ordered list
- Education table
- Two featured web projects plus additional programming projects
- Original profile image with descriptive alternative text
- Internal navigation and styled GitHub repository links
- Ordered and unordered list structures
- Client-side form validation, success feedback, responsive navigation, keyboard support, and reduced-motion support
